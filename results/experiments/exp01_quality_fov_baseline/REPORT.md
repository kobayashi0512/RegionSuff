# Exp01：眼底图像质量、视野与诊断充分性基线

## 研究问题

对完整 UWF 图像模拟一个中心视野，观察局部图像是否会导致 DR 严重程度低估，并判断这种低估风险能否从当前图像中预测。

## 数据与设置

- UWF-DR：1630 张，Normal/NPDR/PDR。
- 原始文件提供 train/val/test，但存在少量同一患者跨划分情况；最终实验重新按患者分组划分。
- 最终 patient-level 划分：train 876 张/602 患者，val 364 张/54 患者，test 390 张/127 患者。
- 模拟中心视野：以非黑区域为基础取中心 55% 区域。
- 特征：亮度、对比度、梯度清晰度、非黑区域比例、径向区域统计和 4×4 空间统计，共 67 维。
- 模型：NumPy 多分类逻辑回归；风险头为二分类逻辑回归。

## 首轮结果

| 指标 | 完整 UWF | 模拟中心视野 |
|---|---:|---:|
| Test accuracy | 0.574 | 0.623 |
| Test macro-F1 | 0.561 | 0.619 |
| Test severity MAE | 0.513 | 0.441 |
| 中心视野低估率 | — | 0.151 |

中心视野分类性能更高不能解释为中心视野更好。当前基线只是手工特征模型，完整 UWF 的空间变化更复杂；这说明后续模型必须显式建模视野和空间结构，而不能只比较一个分类 AUC。

## 低估风险预测

低估定义为：中心视野预测等级低于完整 UWF 的临床标签。

| 风险信号 | Validation AUROC | Test AUROC |
|---|---:|---:|
| 组合风险头 | 0.696 | 0.749 |
| 单纯质量代理分数 | 0.685 | 0.562 |
| 分类熵 | 0.681 | 0.653 |

这说明“低估风险”比单纯图像清晰度或分类熵包含更多信息，支持继续研究病种条件的诊断充分性。

## 重要限制

1. 中心视野来自 UWF 几何裁剪，不是真实同步采集的 45° 图像。
2. 当前 UWF-DR 数据没有眼科医生的质量标签，因此 quality_proxy 只是描述性指标。
3. 首轮模型是可解释的轻量基线，不是最终深度网络。
4. 数据集本身经过筛选且规模有限；下一步需要真实普通 CFP 外部测试和更强的视觉模型。

## 产物

- `results.json`：完整结果。
- `test_predictions.csv`：每张测试图的完整/中心预测、低估标签和风险分数。
- `feature_meta_summary.csv`：视野、亮度、对比度、清晰度等统计。
- `run_baseline.py`：可重复运行脚本。
