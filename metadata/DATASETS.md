# Dataset provenance

| Dataset | Role in this project | Original source | GitHub archive policy |
|---|---|---|---|
| UWF-DR | Source development, controlled perturbation, internal evaluation | Figshare DOI: `10.6084/m9.figshare.31259494` | Original source ZIP retained as a private Release asset |
| MMRDR-UWF | Independent same-modality UWF external severity evaluation | Figshare DOI: `10.6084/m9.figshare.29423747.v2` | Original source ZIP is split into Release assets below 2 GiB each |
| MSHF IQA | Exploratory external image-quality evaluation | Figshare article `21507564` | Original source ZIP retained as a private Release asset |
| RFMiD 2.0 | Cross-disease and image-type exploratory analyses | Zenodo DOI: `10.5281/zenodo.7505822` | Original source ZIP retained as a private Release asset |
| IDRiD | Auxiliary zero-shot exploratory analysis | Zenodo source package | Original source ZIP retained as a private Release asset |
| SUSTech/SYSU | Auxiliary zero-shot exploratory analysis | Figshare source package | Original source ZIP retained as a private Release asset |

Not all listed datasets define the manuscript's primary endpoint. The primary manuscript uses UWF-DR for source development and MMRDR-UWF for independent external evaluation. Complete local provenance, paths, byte sizes, SHA-256 digests, and release-asset names are recorded in `ASSET_MANIFEST.tsv`.

The project does not grant any new rights to third-party images, labels, or metadata. Reuse must follow the original licenses and terms.
