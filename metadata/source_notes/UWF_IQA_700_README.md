# UWF IQA 700：公开临床质量标注数据记录

来源：Springer Nature Figshare article `26936446`。

公开元数据显示：

- 700 张高分辨率 UWF 图像；
- 3 名眼科医生的质量标注；
- 视野、照明、对比度、伪影、总体质量 5 个二元质量维度；
- 诊断、年龄、性别、眼别等临床信息；
- 原始 `Dataset.zip` 大小约 9,018,811,972 bytes（约 9.0 GB）。
